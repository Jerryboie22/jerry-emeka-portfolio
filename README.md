## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Jerryboie22/jerry-emeka-portfolio.git
```

Navigate into the project

```bash
cd jerry-emeka-portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
